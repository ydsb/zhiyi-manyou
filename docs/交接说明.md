## 一·补、服务是怎么起来的（**换会话前必读**）

当前运行的三个服务都是**上一个 AI 会话用后台 job 启动的**，因此：

| 服务 | 端口 | 会话结束后会怎样 |
|---|---|---|
| Spring Boot 后端 | 8080 | **随会话 job 一起被终止**（`job_kill` 会连进程树一起杀） |
| Vite 前端 | 5173 | 同上 |
| NLP 语义服务 | 8901 | 同上（缺了不会崩，只会降级为规则词典） |

**结论：关掉 AI 会话后，网站就不可用了，需要自己重新启动。** 启动顺序：

```powershell

$env:ZHIYI_JWT_SECRET  = '<任意足够长的随机串>'
& G:\DEV\jdk17\bin\java.exe -Dfile.encoding=UTF-8 -Duser.timezone=Asia/Shanghai `
    -jar G:\DEV\zhiyi-manyou-repo\backend\zy-server\target\zy-server.jar

# 2) NLP 语义服务（可选；不起则智能抽取降级为规则词典）
$env:PYTHONPATH = 'G:\DEV\python-venv\Lib\site-packages'
& G:\DEV\python-venv\Scripts\python.exe G:\DEV\zhiyi-manyou-repo\nlp-service\serve.py --port 8901

# 3) 前端
cd G:\DEV\zhiyi-manyou-repo\frontend

```

> 启动后先跑一次 **`powershell -ExecutionPolicy Bypass -File .\check-lan.ps1`**：
> 它会用「外部设备视角」验证 8 项，并直接打印可以发给室友的地址。
> **不要用 `localhost` 判断"能不能用"** —— 本项目踩过两次坑，
> 都是本机一切正常、外部完全不可用（详见第五节 21/22 条）。

**后端 jar 被锁的问题**：后端一旦在跑，`mvn clean package` 会失败

## 五、必须避开的坑（全部是实际踩过的）

### 后端

1. **枚举常量实参不支持前向引用** → 状态机流转规则用 `switch` 写在方法体内。
2. **`@TableField(typeHandler=...)` 对 MyBatis 自动结果映射无效** → 所有枚举列统一以**枚举名 VARCHAR** 存储。
3. **`new ObjectMapper()` 会绕过 JSR-310 模块** → 过滤器/处理器必须**注入**容器里的 ObjectMapper。
4. **返回非 200 会走 `/error` 导致响应体丢失** → 业务错误统一 **HTTP 200 + code**。
5. **MyBatis-Plus 会覆盖数据库默认值**：insert 会把实体全部字段（含 null）写进 SQL，显式 NULL 覆盖 `DEFAULT CURRENT_TIMESTAMP`。自动时间戳必须在 `MybatisPlusConfig` 的 MetaObjectHandler 里 fill（已含 `createdAt`/`updatedAt`/`occurredAt`）。
6. **`Map.of()` 的 `get(null)` 抛 NPE**（不可变 Map 不接受 null 键）→ key 可能为 null 时用 `LinkedHashMap`。
7. **注解式 `@Select` 不解析 XML 实体** → 写 `<>` 而不是 `&lt;&gt;`。
8. **Lombok 实体不要写与字段同名的 `is*()`**：`Integer anonymous` 已有 `getAnonymous()`，再写 `boolean isAnonymous()` 会构成歧义 getter，MyBatis 抛 `Illegal overloaded getter method with ambiguous type`。
9. **参与哈希的字段必须可逐字节重现**：MySQL **JSON 列**读写往返会改格式（加空格、重排），**不能纳入哈希**。M6 为此另存 `dim_canonical` 规范串。
10. **配额校验不要在"接受邀约"里重复做**：邀约阶段已占用配额，重复校验会把自己也算进去，导致"配额满时无法接受"。
11. **图谱游走跳数 ≤ 2**：稀疏图里 3 跳几乎能连上任意两点，会把不相关需求算成"间接互补"。
12. **新增接口记得同步 `SecurityConfig` 白名单**（`/api/certificates/**` 就漏过一次，导致匿名验真返 401）。
13. **不要并发跑多个 Maven 进程**：会报 `另一个程序正在使用此文件`。

### 前端

14. **`el-col` 必须显式给 `:span`**：只写 `:xs="8"` 会同时生成 `el-col-24` 并覆盖响应式类导致竖排。
15. **Vite 8 的 `manualChunks` 必须是函数**，对象写法已不支持。
16. **DTO 时间字段必须声明 `LocalDateTime`**，不要用 String：否则绕过全局序列化器产出 ISO 格式，前端 `new Date()` 解析失败（曾显示 "NaN 天前"）。

### 脚本与测试

17. **`.ps1` 文件必须纯 ASCII**：中文 Windows 的 PowerShell 5.1 按 GBK 解析无 BOM 的 .ps1，中文注释会导致解析错位、报出莫名其妙的语法错误。
18. **`-Dfile.encoding=UTF-8` 不要放进 `$env:JAVA_TOOL_OPTIONS`**：PowerShell 会吃掉 `-D` 参数里的点号。用参数数组。
19. **用 PowerShell 的 `HttpWebRequest` 测带 body 的接口会假性 401**：一旦调用 `GetRequestStream()` 就锁定请求头，之后再 `Headers.Add('Authorization',...)` 不生效。**先加头再写 body**，或直接用 `Invoke-RestMethod`。
20. **用 `Invoke-RestMethod` 测业务错误会误判**：项目约定业务错误返回 HTTP 200 + code，它对 HTTP 200 不抛异常，`try/catch` 会走成功分支。**必须显式检查响应体的 `code`**（`smoke-test.ps1` 的 `Invoke-Probe` 就是这么做的）。
21. **Spring 6 的 CORS `[*]` 只对端口段生效**。写成
    `"http://10.[*].[*].[*]:[*]"` 主机名段会被 `Pattern.quote` 当成**字面量**，
    规则静默失效 —— 不报错、启动日志照常打印模式列表，只是永远匹配不上。
    正确写法是 `"http://10.*.*.*:[*]"`（主机名段用 `*`）。
    症状极具迷惑性：**GET 等简单请求全部正常，只有带
    `Content-Type: application/json` 的 POST 返回 `403 Invalid CORS request`**
    —— 表现为"页面能打开，但一登录就失败"。
    已由 `CorsOriginTest`（11 个用例）钉住，另有 `CorsProbe2.java` 可复现对比。
22. **Vite 的开发代理会自己应答 OPTIONS 预检**（返回 204 及其自带的
    `Access-Control-Allow-Methods`），**不转发给后端**。所以：
    - 经 5173 发预检**永远查不出**后端 CORS 白名单的问题，必须直连后端端口验证；
    - 反过来，`changeOrigin: true` **只改写 `Host`，不改写 `Origin`**，
      所以后端确实会收到局域网 Origin，白名单必须放行它。
23. **`allowedHosts` 只接受域名，不接受 IP**：想放开 Vite 的 host check
    要写 `allowedHosts: true`，写 `'10.51.101.24'` 是无效的。
24. **PowerShell 变量的两个经典撞名**：`$home`（撞只读内置 `$HOME`）、
    `$pid`（撞内置 `$PID`）。变量名大小写不敏感，赋值会直接失败，
    且报错位置往往指向别的行。改用 `$homePage` 之类。
25. **`helper @(1,2,3)` 内联数组字面量会让 PowerShell 5.1 解析错位**，
    报出指向无关行的 `Missing '=' operator after key in hash literal`。
    改为带参数类型声明的函数（`param([int[]]$Codes)`）即可。

### 前端（续）

26. **循环引用会让 element-plus 的命名导出在守卫里取不到**：
    `router → store → api/request → router` 这个环导致路由守卫中调用
    `ElMessage.warning()` 抛 `ElMessage is not defined`。
    改用 `ElMessage({ type: 'warning', message })`（它是可调用对象）即可绕开。
